## 🚀 Git Terminal Commands

Execute the following commands in your terminal to initialize Git, add files, commit them, and push them to your GitHub account:

1. **Open your terminal** (PowerShell or Command Prompt).
2. **Navigate to the project directory**:
   ```bash
   cd "c:\Users\bhard\OneDrive\Desktop\customer\Customer-Churn-Prediction"
   ```
3. **Initialize Git**:
   ```bash
   git init
   ```
4. **Stage all project files**:
   ```bash
   git add .
   ```
5. **Commit the files**:
   ```bash
   git commit -m "Initial Commit - Telco Customer Analytics"
   ```
6. **Set default branch to main**:
   ```bash
   git branch -M main
   ```
7. **Link your local repository to your remote GitHub repository** (replace `YOUR_USERNAME` with your actual GitHub username):
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/Telco-Customer-Analytics.git
   ```
8. **Push the code to GitHub**:
   ```bash
   git push -u origin main
   ```
